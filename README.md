# Northlight Electrical: concept website

A concept website by [Mago Labs](https://magolabs.in) for a fictional electrician in Newcastle, NSW. Northlight Electrical is not a real business: the name, logo, lead electrician, phone number, projects and service details are invented, and the photos are stock images from Unsplash.

React, Vite and Tailwind.

- `npm install` then `npm run dev` to run locally, `npm run build` to build into `dist/`
- `src/data/secData.ts`: business details, services, showcase stages, gallery and FAQs
- `public/img/`: optimised photos
- `public/js/fx3d.min.js`: WebGL 3D lightning bolt in the hero (three.js, loaded after the page renders)
